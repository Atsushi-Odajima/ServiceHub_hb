ServiceHub 説明書 — 予約とシフト
============================================================

この説明書でわかること
・サービス(所要時間、準備・片付け時間、定員、必要なリソース、事前
  質問)と、リソース(部屋・ベッド・設備)の設定方法
・シフト(週テンプレート、シフトの生成、1日ごとの変更、休暇)の登録
・空き枠が決まるしくみ、スタッフ側での予約の作成・変更・キャンセルと
  予約の状態
・お客様がWebで予約する流れと、予約の確認・変更・キャンセル用リンク


■ 1. 予約を受け付けるまでの準備

次の順番で設定すると、スムーズに予約を受け付けられます。
1. 拠点の営業時間 … メニュー → 設定 → 拠点(「複数店舗の設定.txt」)
2. リソース … メニュー → 設定 → リソース(この説明書の「■ 3」)
3. サービス … メニュー → 設定 → サービス(この説明書の「■ 2」)
4. スタッフ … メニュー → 設定 → スタッフ で所属拠点と対応サービスを
   設定(「スタッフと権限.txt」)
5. シフト … メニュー → シフト(この説明書の「■ 4」)
※ スマホでは画面下の「メニュー」から各画面を開きます。
※ 1〜4の設定はオーナーが行います(リソースはマネージャーも可)。
  シフトはオーナーとマネージャーが登録します。


■ 2. サービスを設定する(オーナー)

メニュー → 設定 → サービス を開くと、サービスの一覧(「名称」
「所要時間」「定員」「提供拠点」「公開」「回数券/プラン」)が表示
されます。「サービスを追加」で新しいサービスを作り、名称を押すと
編集できます。
編集画面には「基本・予約ルール」「拠点・スタッフ・リソース」
「事前質問」の3つのタブがあります。「事前質問」タブは、サービスを
一度保存した後に表示されます。

◆ 「基本・予約ルール」タブ
「基本情報」の欄
・「名称」(必須)、「カテゴリ」、「表示順」、「説明」
・「価格表示(任意・表示のみ)」 … 例: 8,800円(税込)。予約ページに
  表示する案内用の文字で、決済は行いません。
・「注意事項(予約時に表示)」 … お客様の予約内容の確認画面や確認
  メールに表示されます。

「時間と定員」の欄
・「所要時間(分)」 … サービスの時間です(5分以上)。
・「準備時間 before(分)」「片付け時間 after(分)」 … サービスの前後に、
  スタッフと部屋を確保しておく時間です。お客様に表示される時間は
  所要時間だけです。
  例: 片付け時間10分の「30分体験」を10:00に予約すると、お客様の予定は
  10:00〜10:30、スタッフと部屋は10:40まで確保されます。
・「定員(同時に受ける人数)」 … 1なら1対1のサービス、2以上なら
  クラス(定員制)になります(「■ 11」)。
・「1予約あたりの最大人数」 … 1回の予約で申し込める人数です。
  定員以下にします。
・「開催時刻」
  - 「営業時間内の空き時間(刻み)」 … 営業時間の中で、時間刻みごとに
    開始時刻の候補ができます。
  - 「曜日ごとの固定開始時刻(クラス)」 … 「拠点・スタッフ・リソース」
    タブで登録した曜日・時刻だけが開始時刻になります。

「予約の受付」の欄
・「時間刻み(拠点設定を上書き)」 … 「拠点の設定に従う」のままなら、
  拠点の「予約の時間刻み」を使います。
・「最短予約時間(分前・空欄=拠点設定)」「受付期間(日先・空欄=拠点
  設定)」 … Web予約の制限を、このサービスだけ変えたいときに入力します。
・「予約を受け付ける」 … オフにすると、スタッフ側でもWebでも新しい
  予約ができなくなります。
・「公開予約ページに表示する」 … オフにすると、Web予約ページに出なく
  なります(スタッフ側からは予約できます)。
・「スタッフの担当が必要(オフ=部屋の貸出など)」 … オフにすると、
  スタッフのシフトや予定を見ずに、必要なリソースの空きだけで予約を
  受け付けます。
  【注意】このチェックをオフにするサービスには、必ず「必要な
  リソース」を設定してください。リソースも拠点の「同時受付上限」も
  ない場合、同じ時間に何件でも予約が入ってしまいます。
・「回数券を利用できる」「利用プランの対象」 … 「回数券の使い方.txt」
  「利用プランの使い方.txt」を見てください。
入力したら、画面下の「保存する」を押します。

◆ 「拠点・スタッフ・リソース」タブ
・「提供する拠点」 … このサービスを提供する拠点にチェックします。
・「担当できるスタッフ」 … 担当できるスタッフにチェックします
  (「スタッフの担当が必要」がオンのサービスだけ表示されます)。
  スタッフの設定の「対応サービス」と同じ設定です。
・「必要なリソース(部屋・ベッド・機材など)」
  1. 「+ 必要なリソースを追加」を押します。
  2. 「名称」(例: 個室)と「必要数」を入力します。
  3. 「候補リソース」にチェックします。予約のときに、候補のうち空いて
     いるものが自動で確保されます。候補には「提供する拠点」にチェック
     した拠点のリソースが「名前(拠点名)」の形で表示されるので、
     拠点ごとに候補を選んでください。
  ・候補を1つも選ばないと保存できません。
  ・必要条件を複数設定すると、すべてを同時に確保できる時間だけが空き枠
    になります。
  ・不要になった条件は「この条件を削除」で消します。
・「固定開始時刻(クラスの時間割)」(「開催時刻」を固定開始時刻に
  した場合)
  拠点・曜日・開始時刻を選んで「追加」を押します。消すときは「削除」。
  例: サンプル組織の「6名ヨガ」は、新宿店で毎日11:00と19:00です。
  ※ 固定開始時刻でも、営業時間の中に収まらない時刻は空き枠に出ません。
このタブの変更も、画面下の「保存する」で保存します。

◆ 「事前質問」タブ
お客様がWebで予約するときに答えてもらう質問を設定します。
【注意】事前質問は予約の準備のための簡単な確認用です。病歴・症状など
医療問診の用途には使用しないでください。
1. 「+ 質問を追加」を押します。
2. 「質問文」「回答形式」「補足説明」を入力し、答えてもらう必要が
   あれば「必須」にチェックします。
   回答形式: 短文/長文/単一選択/複数選択/はい/いいえ/確認(同意)
   単一選択・複数選択は、「+ 選択肢を追加」で選択肢を2つ以上作ります。
3. 並べ替えは「↑ 上へ」「↓ 下へ」、削除は「質問を削除」です。
4. 「事前質問を保存」を押します。
・質問を変えても、受付済みの予約の質問と回答は予約した時点の内容の
  まま残ります。
・回答は、予約の詳細画面の「事前質問への回答」に表示されます。
・スタッフ側の予約作成画面には、事前質問の入力欄はありません。

◆ サービスをアーカイブする
編集画面の「アーカイブ」を押し、確認画面で実行します。
・新しい予約を受け付けなくなります。既存の予約と履歴はそのまま残り
  ます(今後の予約がある場合は件数が表示されます)。
・一覧で「アーカイブ済みも表示」にチェックすると表示され、
  「アーカイブを解除」で元に戻せます。


■ 3. リソース(部屋・ベッド・設備)を設定する(オーナー・マネージャー)

メニュー → 設定 → リソース を開くと、拠点ごとにリソースが一覧表示
されます(マネージャーは担当拠点のみ)。

◆ リソースを追加する
1. 「リソースを追加」を押します。
2. 「拠点」「名称」「種類」(部屋・施術室/ベッド/スタジオ/機材/
   車両/その他)「同時利用数」「メモ」を入力します。
   「同時利用数」は、同じ時間に同時に使える数です(通常は1)。
3. 「保存する」を押します。
・リソースの拠点は、追加した後は変更できません。
・クラス(定員制)のサービスは、参加人数に関係なく、1回の開催で
  「必要数」の分だけリソースを使います。

◆ 一時的に使えなくする
・期間を決めて止める(メンテナンスなど)
  1. 対象のリソースの「停止期間」を押します。
  2. 「開始」「終了」「種類」(メンテナンス/停止/その他)と、必要なら
     「メモ」を入力して「登録」を押します。
     日時はお使いの端末の時刻で入力します(拠点と同じタイムゾーンの
     端末で操作してください)。
  ・その期間にそのリソースを使う予約がある場合は件数が表示されます。
    予約は自動では変更されません。
  ・登録した停止期間は、同じ画面の一覧の「削除」で取り消せます。
・期間を決めずに止める
  「編集」を押し、「状態」を「停止中(予約に使わない)」にして
  「保存する」を押します。一覧に「停止中」と表示されます。
  元に戻すときは「状態」を「利用可」にします。

◆ リソースをアーカイブする
「編集」の「アーカイブ」を押し、確認の画面で「アーカイブする」を
押すと、一覧に表示されなくなります。画面から元に戻す操作は
ありません。一時的に使わないだけの場合は、「停止中」か
「停止期間」を使ってください。


■ 4. シフトを設定する

メニュー → シフト を開きます。
・オーナー・マネージャー … シフトの追加・変更・削除、週テンプレート、
  テンプレートからの生成ができます(マネージャーは担当拠点のみ)。
・受付 … 担当拠点のシフトを見ることができます(変更はできません)。
・スタッフ … 「自分のシフト」として、自分のシフトだけを見ることが
  できます(変更はできません)。

◆ シフトの種類と予約への影響
・「勤務」 … 予約を受けられる時間です。必ず拠点を指定します。
  準備時間から片付け時間までが勤務の中に収まる時刻だけが、空き枠に
  なります。
・「休憩」「休暇」「研修」「他業務」「予約不可」 … その時間は、どの
  拠点でも空き枠に出ません。「休暇」は拠点を指定せずに登録します。
※ 勤務時間外や休憩などの時間に予約を入れられるのは、オーナー・
  マネージャーの「強制予約」だけです(「■ 7」)。
・休憩は勤務と重ねて登録します(例: 勤務 10:00〜19:00 と
  休憩 13:00〜14:00)。

◆ 画面の見方
・1週間ずつ表示されます。「‹ 前週」「今週」「次週 ›」で移動します。
・担当拠点が2つ以上ある人は、画面上部で拠点を選びます。
・行が選んでいる拠点に所属するスタッフ、列が日付です。シフトは
  「勤務 10:00-19:00」のように表示されます。
・そのスタッフが他の拠点で勤務する日は、そのシフトの後ろに「*」が
  付きます(担当拠点の範囲で表示)。同じ時間に2つの拠点で勤務する
  シフトは登録できません。

◆ 週テンプレートを作る(毎週のくり返しのシフト)
1. スタッフ名の下の「週テンプレート」を押します。
2. 「+ 行を追加」を押し、曜日・種類(勤務/休憩)・拠点・開始〜終了を
   選びます。行を消すときは「削除」を押します。
3. 「保存する」を押します。
・週テンプレートは、そのスタッフの全拠点分をまとめて1つとして保存
  します(例: 月水金は池袋店、火木土は新宿店)。
・拠点は、そのスタッフの所属拠点から選びます。
・同じ曜日の勤務どうしが重なると保存できません(別の拠点でも同じ)。
・テンプレートを保存しただけではシフトはできません。次の「生成」を
  行ってください。

◆ テンプレートからシフトを生成する
1. 画面上部で拠点を選び、「テンプレートから生成」を押します。
2. 「開始日」「終了日」を入力します(最大92日。初めは表示中の週の
   月曜日から4週間が入っています)。
3. 「生成する」を押します。
   「作成 ○件 / 既存のためスキップ ○日 / 休業日のためスキップ ○件」と
   結果が表示されます。
・表示中の拠点に所属するスタッフが対象です。複数の拠点で働くスタッフ
  は、週テンプレートにある他の拠点の分も一緒に作られます(担当拠点が
  限られたマネージャーが生成した場合は、担当拠点の分だけ)。
・その日にすでにシフト(休暇なども含む)が1つでもあるスタッフの日は、
  上書きせずにスキップします。個別に変更した日が消えることはありません。
・拠点の定休日・臨時休業日はスキップします。
・シフトは先の日付まで自動では作られません。定期的に(例: 4週間ごと)
  生成してください。

◆ 1日のシフトを追加・変更・削除する
・追加: その日の欄の「+ 追加」を押し、「種類」「拠点」(休暇以外)
  「開始」「終了」「メモ」を入力して「保存する」を押します。
・変更: シフトの表示(例:「勤務 10:00-19:00」)を押し、内容を変えて
  「保存する」を押します。
・削除: シフトの表示を押し、「削除」を押します。
・日付をまたぐ勤務(例: 22:00〜翌2:00)は1件では登録できません。
  2日に分けて登録します。
・勤務は、そのスタッフの所属拠点でしか登録できません(所属していない
  拠点を選ぶと「このスタッフはその拠点に所属していません」と表示され
  ます)。

【注意】すでに入っている予約と合わなくなる変更(勤務を短くする・消す、
休暇や予約不可を入れるなど)をすると、「既存の予約○件と競合します。」
と表示され、対象の予約と理由(「勤務時間外になります」「休憩・休暇・
予約不可の時間と重なります」)が一覧で出ます。予約は自動では削除・
移動されません。内容を確かめて、よければ「競合を承知で保存」を押し
ます(削除の場合は、もう一度「削除」を押します)。その後、予約の担当
変更やお客様への連絡を行ってください。

◆ 休暇や、特定の時間だけ予約を止めたいとき
・休暇 … 種類「休暇」で登録します。すべての拠点で空き枠に出なくなり
  ます。
・特定の時間だけそのスタッフの予約を止める … 種類「予約不可」で登録
  します。
・拠点全体の予約を止める … 設定 → 拠点 の「予約受付停止」を使います
  (「複数店舗の設定.txt」)。


■ 5. 空き枠が決まるしくみ

お客様のWeb予約でも、スタッフ側の予約作成でも、同じしくみで空き枠
(予約できる開始時刻)が決まります。

◆ 1) 開始時刻の候補を作る
・「営業時間内の空き時間(刻み)」のサービス … 時間刻みごとの時刻
  (30分刻みなら 10:00、10:30、11:00 …)のうち、所要時間がその日の
  営業時間の中に収まる時刻。
・「曜日ごとの固定開始時刻(クラス)」のサービス … 登録した曜日・
  時刻のうち、所要時間が営業時間の中に収まる時刻。
・その日の営業時間は、臨時休業・特別営業の登録があればそちらが優先
  されます。

◆ 2) 候補のうち、次の条件をすべて満たす時刻だけが空き枠になります
・拠点とサービスが予約を受け付けている(Web予約では、拠点とサービスが
  両方とも公開予約ページに表示する設定になっている)
・人数が「1予約あたりの最大人数」と「定員」の範囲内
・拠点の「予約受付停止」の時間帯と重ならない
・過去の日時ではない
・Web予約の場合は、最短予約時間より先で、受付期間の範囲内
・スタッフが有効で「予約を受け付ける」がオン、その拠点に所属し、
  そのサービスを担当できる
・スタッフの準備時間〜片付け時間が、その拠点の「勤務」の中に収まる
・その時間が、スタッフの休憩・休暇・研修・他業務・予約不可と重ならない
・同じスタッフの他の予約(他の拠点の予約を含む)と重ならない
・拠点間の移動時間を設定している場合は、別の拠点の予約との間が移動
  時間以上空いている
・必要なリソースを必要数だけ確保できる(停止中・停止期間中のものは
  使いません)
・クラスの場合は、定員に空きがある
・拠点の「同時受付上限」を超えない
※ 「スタッフの担当が必要」がオフのサービスは、スタッフの条件を見ずに
  判断します。

◆ 3) 担当を指定しない(おまかせ)の場合
条件を満たすスタッフが1人でもいれば空き枠になります。割り当ては、
同じ時刻のクラスに入れるスタッフ → その日の担当時間が少ないスタッフ
→ スタッフの「表示順」の順で決まります。

◆ 例(サンプル組織の設定の場合)
池袋店(営業 10:00〜20:00、30分刻み)で「60分パーソナル」を予約する
とき、Aki の勤務が 10:00〜19:00、休憩が 13:00〜14:00 の日は、Aki の
空き枠は 10:00・10:30・11:00・11:30・12:00 と 14:00〜18:00 の30分
ごとになります(他の予約がない場合)。
このサービスの池袋店の個室の候補は Room A だけなので、Mika が 11:00
から同じサービスの予約を持っていると、Room A が使われているため、
Aki の 11:00 の枠も出なくなります。


■ 6. 予定表で1日の予約を見る

メニュー → 予定表(スマホでは画面下の「予定」)
・「‹ 前日」「今日」「翌日 ›」または「日付」で日を選びます。担当拠点
  が2つ以上ある人は「拠点」も選びます。
・表示は「担当者別」と「リスト」を切り替えられます(画面の幅が狭い
  スマホでは、最初は「リスト」になります)。
・キャンセルや無断欠席の予約も見たいときは「キャンセル・無断欠席も
  表示」にチェックします。
・「担当者別」では、選んでいる拠点に所属するスタッフごとに列が並び
  ます。
  - 斜線の部分は勤務時間外です。
  - 休憩・休暇などは、その名前で表示されます。
  - グレーの枠は、そのスタッフの他の拠点での予約・勤務です(「他拠点の
    予約(拠点名)」「他拠点勤務(拠点名)」)。この拠点では予約できま
    せん。
  - スタッフが担当しないサービスの予約は「担当なし(部屋・設備のみ)」
    の列に表示されます。
  - クラスは1つの枠に「サービス名 人数/定員名」と参加者の名前が表示
    され、押すと参加者の一覧が開きます。
・予約を押すと、予約の詳細画面が開きます。
・「予約を作成」を押すと、選んでいる拠点と日付が入った状態で予約の
  入力画面が開きます。
・他の端末での変更は自動で反映されます。
・スタッフロールの人には、自分の予約だけが表示されます。
※ 「この拠点に所属するスタッフがいません」と表示された場合は、
  設定 → スタッフ で所属拠点を設定してください。


■ 7. スタッフ側で予約を作成する

予約の入力画面は、次の場所から開けます。
・予定表・予約(一覧)の「予約を作成」
・ダッシュボード・受付モードの「＋ 当日の予約」(受付モードを使える
  ロールの場合)
・完了した予約の「次回予約を取る」(「■ 13」)
・待機リストの「この枠で予約」(「■ 12」)

◆ 予約を作成する手順
1. 「顧客」の欄で、「顧客を検索」に氏名・フリガナ・電話番号(下4桁
   でも可)・メールのどれかを入力し、候補の「選択 ›」を押します。
   見つからない場合は「+ 新規顧客として登録」を押し、「氏名」(必須)
   「フリガナ」「電話」「メール」を入力します。
2. 「拠点」(担当拠点が2つ以上ある場合)、「サービス」、「担当」、
   「人数」(複数人で予約できるサービスの場合)、「日付」を選びます。
   「担当」を選ばないと「おまかせ(空いているスタッフ)」になります。
3. 空き枠のボタンから開始時刻を選びます。
   ボタンの小さな文字は、おまかせのときは担当できる人数(「○名可」)、
   クラスで担当を選んだときは残りの人数(「残○」)です。
   空き枠がない日は「この日は空き枠がありません。日付・担当を変えて
   ください。」と表示されます。
4. 必要なら「お客様の要望」「内部メモ(お客様には表示されません)」を
   入力します。
5. 「予約を確定」を押すと予約が確定し、予約の詳細画面が開きます。
・スタッフロールの人は、担当が自分に固定されます。
・組織・運営ルールで「予約確定」のメール通知がオンで、顧客にメール
  アドレスがある場合は、確認メールが送られます。
  ※ メールは、運用担当がメール送信(SMTP)を設定するまで実際には
    送信されません(記録のみ)。サンプル組織では常に送信されません。

◆ 強制予約(オーナー・マネージャー)
空き枠に出ない時刻に、理由を記録したうえで予約を入れる機能です。
1. サービスを選んだ後、「時刻を直接指定する(営業時間外・シフト外
   などを理由付きで強制予約)」にチェックします。
2. 「開始時刻」を入力します(拠点の時間で入力します)。
3. 判定の結果が表示されます。
   ・「この時刻は通常どおり予約できます。」
   ・「次のルールを上書きして予約します:」と、上書きするルールの一覧
   ・「この時刻は予約できません(強制でも不可):」と、その理由
4. ルールを上書きする場合は「強制予約の理由」を入力し(監査ログに記録
   されます)、「強制予約する」を押します。
・上書きできるルールの例: 営業時間外、スタッフの勤務時間外、休憩・
  休暇などの時間、予約受付停止の時間帯、同時受付上限
・上書きできないもの: スタッフの他の予約との重なり(他の拠点を含む)、
  拠点間の移動時間、必要な部屋・設備の不足、定員を超える予約、担当
  できないスタッフ、その拠点で提供していないサービス、人数の上限
・強制予約した予約の詳細画面には「強制予約(ルールを上書きして作成)」
  と表示されます。


■ 8. 予約の確認・変更・キャンセル

◆ 予約の一覧
メニュー → 予約 を開くと、「拠点」「開始日」「終了日」「状態」で
絞り込んだ予約が、「日時」「顧客」「サービス」「担当」「状態」
「予約番号」の一覧で表示されます(初めは今日から7日後まで)。
行を押すと予約の詳細画面が開きます。

◆ 予約の詳細画面
・「予約内容」(日時・拠点・サービス・担当・部屋・設備・お客様の要望
  など)と「顧客」が表示されます。画面上部には予約番号と、予約の入り口
  (「公開予約」「スタッフ」「受付」「待機から」など)が表示されます。
・「受付・対応」の欄で、来店・対応開始・完了・無断欠席を操作します
  (「■ 9」)。
・「事前質問への回答」「内部メモ」「履歴」も確認できます。
  内部メモは受付のメンバーには表示されません。

◆ 日時・担当を変更する
1. 「日時・担当を変更」を押します(予約の状態が「来店待ち」のとき
   だけ表示されます)。
2. 「日付」と「担当」を選び、空き枠から新しい時刻を選びます。
3. 「変更する」を押します。
・変更できなかった場合、元の予約はそのまま残ります。
・日時が変わった場合は、組織・運営ルールで「予約変更」の通知がオンなら
  お客様に変更のお知らせメールが送られます(メール送信の設定がある
  場合)。
・スタッフロールの人は、担当を変えることはできません。
・予約の拠点を変える操作はありません(「複数店舗の設定.txt」)。

◆ キャンセルする
1. 「キャンセル」を押します(「来店待ち」「来店済み」のとき)。
2. 「キャンセルの区分」で「お客様都合(顧客キャンセル)」か「店舗都合
   (事業者キャンセル)」を選び、必要なら「理由(任意)」を入力します。
3. 「キャンセルする」を押します。
・キャンセルした枠は、すぐに再び予約できるようになります。
・キャンセル締切を過ぎてからのお客様都合のキャンセルは、回数券・
  利用プランを消化するかどうかを運営者が確認する対象になります
  (自動では消化しません)。詳しくは「キャンセル・無断欠席.txt」を
  見てください。

◆ キャンセル・無断欠席を取り消す(オーナー・マネージャー)
間違えてキャンセル・無断欠席にした場合は、「キャンセル/無断欠席を
取り消す」を押して確認画面で実行します。
・同じ日時の枠を再び確保できた場合だけ元に戻ります(その間に他の予約
  が入っていると戻せません)。
・キャンセルは「来店待ち」に、無断欠席は「来店済み」に戻ります。
・開始時刻を過ぎた予約など、上書きできるルールだけで戻せない場合は、
  理由を入力して「理由を記録して復元(強制)」で戻せます
  (「キャンセル・無断欠席.txt」の7章)。
・回数券・利用プランの消化がある場合は、先に消化を取り消してください。


■ 9. 予約の状態

予約の状態は、色だけでなく記号と文字で表示されます。
・○ 来店待ち … 予約が確定し、来店を待っている状態です(予約直後)。
・● 来店済み … 「● 来店済みにする」を押した状態です。
・▶ 対応中 … 「▶ 対応開始」を押した状態です。
・✓ 完了 … 「✓ 完了・実施記録」から完了にした状態です。
・× キャンセル(顧客) … お客様都合のキャンセルです(お客様がWebで
  キャンセルした場合もこれになります)。
・× キャンセル(事業者) … 店舗都合のキャンセルです。
・! 無断欠席 … 「! 無断欠席」を押した状態です。予約の枠は空き、
  その時間を他の予約に使えるようになります。

◆ 状態の変え方
・来店待ち → 来店済み・対応中・完了・キャンセル・無断欠席
・来店済み → 対応中・完了・キャンセル・無断欠席
  (「来店を取り消す」で来店待ちに戻せます)
・対応中 → 完了(「対応開始を取り消す」で来店済みに戻せます)
・完了・キャンセル・無断欠席 … ここからは変わりません。
  キャンセル・無断欠席は「■ 8」の取り消し、完了は実施記録の画面の
  「実施を取り消す」(オーナー・マネージャー)で「対応中」に戻せます。

◆ 完了にする
「✓ 完了・実施記録」を押すと「完了・実施記録」の画面が開きます。
「実施内容」(開始時刻・所要時間・メモ・次回のおすすめ日など)を入力
し、「✓ 完了にする」を押します。回数券・利用プランを使う場合は、
消化する券を選んで「✓ 完了して1回消化」を押します(選ばない限り
消化されません)。詳しくは「回数券の使い方.txt」
「利用プランの使い方.txt」を見てください。

◆ お客様の予約確認画面での表示
お客様が予約確認用リンクで見る画面では、状態が次のように表示されます。
「予約確定」「ご来店済み」「ご案内中」「ご利用済み」「キャンセル済み」
「店舗によりキャンセル」「ご来店なし」


■ 10. 同じ枠に同時に予約が入ったとき

・同じ時間を2人が同時に予約しようとした場合でも、確定できるのは先に
  確定した1件だけです。確定の直前に、最新の状況でもう一度確認する
  ためです。
・お客様のWeb予約で間に合わなかった場合は、「申し訳ありません。この
  日時はたった今埋まったか、予約できなくなりました。別の日時をお選び
  ください。」と表示され、最新の空き状況で日時の選択に戻ります。
・スタッフ側で間に合わなかった場合は、「この日時では予約できません:」
  に続けて理由(例: スタッフはこの時間に他の予約があります(他拠点を
  含む))が表示され、空き枠の一覧が最新に更新されます。別の時刻を
  選んでください。
・「予約する」「予約を確定」を2回押したり、通信が途切れて押し直したり
  しても、同じ予約が2件できることはありません。
・他の人が先に同じ予約を変更していた場合は、「他の操作で内容が更新
  されています。」と表示されます。画面を読み込み直してから操作して
  ください。


■ 11. クラス(定員制)の予約

・サービスの「定員(同時に受ける人数)」を2以上にすると、同じ拠点・
  同じ日時・同じ担当の予約が、定員まで1つのクラスにまとまります。
・Web予約の空き枠には「残り○席」と表示されます。
・「1予約あたりの最大人数」を2以上にすると、予約のときに「人数」を
  選べます。
  例: サンプル組織の「6名ヨガ」は、定員6名、1予約2名まで。
・時間割のあるクラスは、「開催時刻」を「曜日ごとの固定開始時刻
  (クラス)」にして、「固定開始時刻(クラスの時間割)」を登録します。
・拠点の「同時受付上限」では、1回の開催を1枠と数えます。
・予定表では1つの枠にまとめて表示されます(「■ 6」)。


■ 12. 待機リスト(キャンセル待ち)

満席のときに、空きが出たら案内してほしいお客様を登録しておく機能
です。メニュー → 待機リスト(オーナー・マネージャー・受付)
・お客様は、Web予約ページで空きがない日に表示される「キャンセル待ちに
  登録する」から登録できます(拠点の「満席時にキャンセル待ち登録を受け
  付ける」がオンの場合)。店舗側では「待機を登録」から登録します。
・希望日は最長31日間です。
・キャンセルなどで空きが出ると、その待機に「空きの候補」が表示され
  ます。予約は自動では確定しません。
・候補ごとに「メールで案内」「連絡済みにする」「この枠で予約」
  「見送る」を選べます。案内や予約は先着順で、その時点の空きで確認
  し直します。


■ 13. 完了した予約から次回予約を取る

1. 完了した予約の詳細画面(または実施記録の画面)で「次回予約を取る」
   を押します。
2. 「次回予約を作成」の画面が、同じ顧客・拠点・サービス・担当が入った
   状態で開きます。日付には、実施記録の「次回のおすすめ日」を入力して
   あればその日、なければ前回の1週間後(今日より前にはなりません)が
   入っています。
3. 空き枠から時刻を選び、「予約を確定」を押します。
・作成すると「次回予約を作成しました」と表示され、新しい予約の詳細
  画面が開きます。前回の実施記録の「次回予約」は「予約あり」になり
  ます。
・スタッフロールの人も、自分が担当した予約から次回予約を取れます。


■ 14. お客様のWeb予約の流れ

◆ 予約ページのアドレス
拠点ごとの予約ページは「(ServiceHubのアドレス)/p/組織のURL名/拠点の
URL名」です(アドレスの確認方法は「複数店舗の設定.txt」)。
組織のページ「(ServiceHubのアドレス)/p/組織のURL名」から店舗を選ぶ
こともできます。

◆ お客様の予約の手順
画面の上部に、手順(サービス → 担当 → 日時 → お客様情報 → 確認)が
番号付きで表示されます(担当を選ぶ手順がない場合は表示されません)。
1. サービス … 「サービスを選んでください」から選びます。価格表示・
   所要時間・定員・説明が表示されます。拠点の「ご案内」もこの画面に
   表示されます。
2. 担当 … 「担当者を選んでください」から、「おまかせ」かスタッフを
   選びます。スタッフの担当が必要なサービスで、拠点の「お客様が
   スタッフを指名できる」がオンの場合だけ表示されます。
3. 日時 … 「日時を選んでください」で、2週間分の日付(○=空きあり
   ×=空きなし)から日を選び、空いている時刻を選んで「次へ」を押し
   ます。「‹ 前の2週間」「次の2週間 ›」で期間を移動できます。
   時刻は店舗の現地時間で表示されます。
4. お客様情報 … 「お名前」「メールアドレス」「電話番号」(必須)と
   「フリガナ」、「事前のご質問」、「ご要望・連絡事項(任意)」を入力
   し、「確認へ」を押します。
5. 確認 … 「予約内容の確認」で内容・料金の目安・注意事項を確かめ、
   「上記の内容と注意事項を確認しました」にチェックして「予約する」を
   押します。
6. 「✓ ご予約が確定しました」と予約番号が表示されます。
   「予約の確認・変更・キャンセル」と「カレンダーに追加(.ics)」の
   ボタンがあります。

・メール送信が設定されている場合は、確認メールがお客様に届きます。
  設定されていない場合(サンプル組織を含む)は、完了画面に「現在この
  予約ページからは確認メールが送信されません。」と表示されるので、
  予約番号とリンクを控えるようお客様に伝えてください。
・画面を開いたまま長い時間(2時間以上)たつと、「画面の有効期限が
  切れたか、送信が早すぎます。空き状況を表示し直してから予約して
  ください。」と表示されることがあります。日時を選び直してください。

◆ 予約の確認・変更・キャンセル(予約確認リンク)
お客様は、完了画面のボタンや確認メールのリンク
「(ServiceHubのアドレス)/b/…」から、予約の内容を確認できます。
・状態が「予約確定」の予約で、キャンセル締切の前であれば、
  「日時を変更する」「キャンセルする」を使えます(拠点の「お客様が
  Webから日時変更できる(締切前のみ)」「お客様がWebからキャンセル
  できる(締切前のみ)」がオンの場合)。
・日時の変更では、今日から2週間分の日付から新しい時刻を選び、
  「この日時に変更する」を押します。担当を指名した予約は、同じ担当の
  空き時間から選びます。
・キャンセルは「キャンセルする」→「キャンセルを確定する」です。
  お客様のWebでのキャンセルは「キャンセル(顧客)」になります。
・締切を過ぎると「Webでの変更・キャンセルの受付は終了しました。」と
  表示され、店舗への電話を案内します。
・リンクは、予約の終了時刻から30日を過ぎると使えなくなります。
・スタッフ側で作成した予約でも、お客様のメールアドレスが登録されて
  いれば、確認メールに同じリンクが記載されます(メール送信の設定が
  ある場合)。
・リンクを知っている人は誰でも予約を確認・変更できるため、お客様には
  他の人に教えないよう案内してください。


■ 15. 困ったとき

Q. 空き枠が出ない(予約ページやスタッフ側の入力画面)。
A. 次を順番に確認してください。
   ・その日が営業日か(営業時間、臨時休業・特別営業、予約受付停止)
   ・サービスの「提供する拠点」にその拠点が入っているか、「予約を
     受け付ける」がオンか(Web予約では「公開予約ページに表示する」も)
   ・スタッフの所属拠点・対応サービス・「予約を受け付ける」
   ・その日のその拠点の「勤務」シフトがあるか(シフトを生成したか)
   ・サービスの「必要なリソース」に、その拠点の候補があるか。候補が
     停止中・停止期間中になっていないか
   ・Web予約の場合は、最短予約時間・受付期間の範囲内か
   ・クラスは固定開始時刻を登録したか、定員に空きがあるか

Q. 「来店前(予約中)の予約のみ変更できます」と表示される。
A. 日時・担当の変更は「来店待ち」の予約だけです。来店済みにした予約を
   変えたい場合は、先に「来店を取り消す」を押してください。

Q. シフトを登録しようとすると「同じスタッフの勤務時間が他の勤務
   (別拠点を含む)と重なっています」と表示される。
A. 同じスタッフの勤務は、拠点が違っても重ねられません。もう一方の
   勤務の時間を確認してください。

Q. 「このスタッフはその拠点に所属していません」と表示される。
A. 設定 → スタッフ で、そのスタッフの「所属拠点(複数可)」に拠点を
   加えてください。

Q. 予約の入力画面や変更の画面で「この日時では予約できません:」と
   理由が出る。
A. 表示された理由(「スタッフの勤務時間外です」「必要な部屋・設備が
   空いていません」など)を確認し、別の時刻や担当を選んでください。


■ ServiceHub 空き枠お知らせ画像(SNS用の告知画像を作る)
--------------------------------------------------
予約の空き状況から、Instagram などに載せる「空き枠のお知らせ」画像(PNG)を
作ります。空いている時間を手で入力する必要はありません。
開き方: メニュー「日々の運営」→「空き枠お知らせ画像」
使える人: オーナー・マネージャー・受付(担当の拠点のみ)。スタッフは使えません。

1. 対象を選ぶ
   拠点・サービス・(担当が必要なサービスは)担当スタッフ・開始日を選びます。
   開始日から7日分が対象です。
   「空きの基準」は次のどちらかです。
   ・公開予約ページと同じ条件 … お客様がWebで予約できる枠だけを数えます
     (受付期間・直前の締切を含みます)。予約ページに出していない拠点・
     サービスでは空きが0になります。
   ・スタッフが予約を入れられる条件 … 電話やDMで受けて店側で入力する場合に。
2. 店舗名・予約方法の案内文・補足文を入れる(この端末に記憶されます)
3. 日ごとの枠を確認する
   空きのある時刻から、1日4枠まで朝〜夜に散らばるよう自動で選びます。
   営業時間のない日は「休業」、空きのない日は「満席」になります。
   ・時刻のボタンを押すと、載せる時刻を手で選べます(4つまで。「(満)」の時刻を
     選ぶと「満席」として載ります)。「枠の選択を自動に戻す」で元に戻ります。
   ・「この日の表示」で、その日を「満席」「休業」に変えられます。
   ・枠ごとに「状態」(空きあり/満席/非表示)と「メニュー名・補足」(12文字まで)
     を変えられます。
   ※ここでの変更は画像だけに反映されます。予約やシフトは変わりません。
4. 画像の種類(週間告知/1枠告知)、配色(ホワイト/ウォームベージュ/チャコール)、
   サイズ(正方形1080×1080/縦長1080×1920)を選び、「画像を保存(PNG)」を押します。
   文字が長すぎて収まらないときは保存できません(理由が表示されます)。

注意
・画像は作った時点の空き状況です。投稿までに予約が入ることがあります。
・SNSへの自動投稿はしません。保存した画像をご自身で投稿してください。
・文字はお使いの端末の日本語フォントで描くため、端末によって形が少し変わります。
