# ServiceHub 開発計画 (PLAN.md)

商品 #016 ServiceHub — 小規模サービス事業 統合運営システム。
公開予約 → 予約枠 → 顧客 → スタッフ/シフト → 拠点/部屋/設備 → 当日受付 → サービス実施 → 回数券/利用枠消化 → 対応履歴 → 次回予約 → 待機リスト → 運営KPI を一つの業務システムで扱う。

- 対象: 美容室、ネイル/まつげ、整体/リラクゼーション、パーソナルトレーニング、ヨガ/ピラティス、スクール、撮影スタジオ、相談、ワークショップ、レンタルスペース等(1〜数拠点)。
- 医療機関向け電子カルテ/診療予約としては販売しない。
- #012 見積/請求、#013 物販在庫、#014 制作物承認は追加しない。オンライン決済・自動課金も初版では実装しない。

## 1. 技術構成 (詳細は DECISIONS.md)

| 層 | 採用 | 理由 |
|---|---|---|
| 言語 | TypeScript 6.0 (Node.js 22 LTS) | 型安全、クライアント/サーバーでスキーマ共有 |
| API | Fastify 5 | 成熟・高速・プラグイン(helmet/cookie/static) |
| DB | PostgreSQL 16 | トランザクション、排他制約(EXCLUDE)、RLS、advisory lock |
| DBアクセス | node-postgres (pg) + 手書きSQL(常にパラメータ化) | ロック/制約/RLSを明示的に制御するため ORM を使わない |
| 入力検証 | Zod 4 | リクエストスキーマ検証、共有型 |
| 日時 | Luxon 3 (IANA timezone) | 拠点タイムゾーンでの営業時間/シフト解釈 |
| フロント | React 19 + React Router 8 + TanStack Query 5 + Vite 8 | 安定構成、SPA |
| PWA | vite-plugin-pwa 1.3 (Workbox 7) | manifest/service worker/限定キャッシュ |
| メール | nodemailer 10 (SMTP) / log プロバイダ | ベンダー非依存。既定は送信しない log |
| ジョブ | PostgreSQL 送信箱テーブル + FOR UPDATE SKIP LOCKED ワーカー | 追加インフラ不要、冪等キーで重複防止 |
| リアルタイム | Server-Sent Events + PostgreSQL LISTEN/NOTIFY | 受付/スタッフ/管理画面の即時反映(複数インスタンス可) |
| テスト | Vitest 5(単体/統合, 実DB) / Playwright 1.56(E2E, 端末エミュレーション) / autocannon(負荷) | |
| 配布 | Dockerfile + docker-compose + render.yaml(Render Blueprint) | 購入者に開発環境を要求しない |

## 2. マルチテナント方式
共有DB・共有スキーマ・全テナントテーブルに `organization_id`。
1. アプリ層: 認証済みセッションから組織IDを決定し、全クエリに `organization_id = $1` を付ける(クライアント入力の組織IDは使わない)。
2. DB層: Row Level Security を全テナントテーブルで ENABLE + FORCE。トランザクション毎に `set_config('app.org_id', ..., true)`。
3. 参照整合: 子テーブルは `(organization_id, xxx_id)` の複合外部キーで親を参照し、他組織の行を参照できない。
4. 起動時に接続ロールが superuser/BYPASSRLS でないことを検査(本番では拒否)。

## 4. 画面構成(概要)
- 公開(ログイン不要): 事業者トップ `/p/:org` → 拠点 `/p/:org/:location` → サービス → スタッフ/おまかせ → 日時 → 顧客情報 → 事前質問 → 確認 → 完了(管理リンク)。予約管理 `/b/:token`。キャンセル待ち登録。
- 管理(ログイン): ダッシュボード(ロール別) / 予定表(日・週, スタッフ別) / 予約 / 受付モード / 顧客 / 回数券 / 利用プラン / 待機 / シフト / KPI / 検索 / CSV / 監査 / 通知履歴 / 設定(組織・拠点・サービス・スタッフ・リソース・メンバー権限・通知・キャンセル規則・バックアップ)。
- PC: サイドバー、表、大量操作。スマホ: 下部タブ(今日/受付/顧客/検索/メニュー)、カード表示。iPad: 受付モード(大きな文字・状態を文字+アイコンで表示)。
