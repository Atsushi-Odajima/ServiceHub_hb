# 運用コスト (OPERATING_COSTS.md)

> **重要**: 以下の金額は 2026-09-30 時点で、開発環境から公式料金ページを直接閲覧できなかったため、**公式ドメインに絞った Web 検索結果の要約**から拾った値です(一部は第三者サイトのみ)。契約・見積・販売ページ掲載の前に、必ず各社の公式料金ページで最新値を確認してください。
> アプリのコードには料金を一切埋め込んでいません(料金変更でコード修正は不要)。
> 一次資料(全出典URL・信頼度区分つき): [pricing_research_2026-09-30.md](pricing_research_2026-09-30.md)

## 1. ServiceHub が必要とするもの

| 費目 | 用途 | 必須/任意 | 備考 |
|---|---|---|---|
| Web サービス(Node.js 22) | API + 画面配信(SPA/PWA) | 必須 | 常時稼働(スリープする無料枠は不可: 予約受付・リマインダーが止まる) |
| ワーカー | 通知送信・スケジューラ | 任意 | 小規模は Web 内で動かせる(`RUN_WORKER=true`)。分離すると Web 再起動中も送信継続 |
| PostgreSQL 16 | 全データ | 必須 | **拡張 `btree_gist` が使えること**(Neon/Supabase は公式で対応確認、Render は未確認→導入時に `CREATE EXTENSION btree_gist` を確認)。接続ロールは superuser/BYPASSRLS 不可 |
| 自動バックアップ/PITR | 障害復旧 | 必須 | マネージドDBの機能を利用 + 組織バックアップ(アプリ機能)を定期保存 |
| トランザクションメール | 予約確定/変更/リマインダー等 | 実質必須 | SMTP 対応事業者。送信ドメインの SPF/DKIM/DMARC 設定が必要 |
| オブジェクトストレージ | オフサイトバックアップ保管 | 推奨 | R2 / B2 等(アプリは標準出力/ファイルにバックアップを作る。アップロードは運用手順で実施) |
| ログ・監視 | 障害検知 | 推奨 | ホスティング内蔵ログ + 外形監視(`/healthz`) |
| ドメイン/HTTPS | 独自ドメイン | 任意 | 多くのPaaSは HTTPS 証明書を無償で自動発行 |
| ファイルストレージ | — | 不要 | 初版はファイル添付機能なし |

## 2. 費用試算の方法(式)
単価が変わったら差し替えて再計算する。USD・税抜。

```
月額合計 = WS + WEB + WRK + PG + BW + MAIL + BK + MON

WS   = ホスティングのワークスペース/プラン料金
WEB  = Web インスタンス月額
WRK  = ワーカー月額(Web 内で動かす場合 0)
PG   = Postgres インスタンス月額 + ストレージGB × GB単価
BW   = max(0, 外向き転送GB − 含まれる転送GB) × 超過単価   ※オフサイトへのバックアップ送信も外向き転送に数える事業者がある
MAIL = メール事業者の月額 + 超過通数 × 単価
BK   = max(0, 保管GB − 無料枠GB) × GB単価
MON  = 監視サービス料金
円/月 = USD/月 × 為替レート(実勢で差し替える)
```

### 利用量の見積り方
| 項目 | 目安(実測前の仮定) | 確認方法 |
|---|---|---|
| メール通数/月 | 予約数 × 約3(確定・リマインダー・変更/キャンセル) + 期限通知 | 管理画面「通知履歴」の月間件数 |
| DBサイズ | 予約1件あたり約 2〜4KB(予約・占有・履歴・通知・監査・索引を含む。負荷試験の実測値は TEST_REPORT.md) | `SELECT pg_size_pretty(pg_database_size(current_database()))` |
| 外向き転送 | 画面配信(初回 約0.5MB, 以後はPWAキャッシュ)+ API応答 | ホスティングのメトリクス |
| バックアップサイズ | DBサイズの 20〜40%(圧縮後) | `pnpm backup:create` の出力サイズ |

## 3. 利用量の仮定と試算(見積り)

### A. 小規模: 1店舗 / 3スタッフ / 1,000顧客 / 約600予約/月 / 約2,000通/月 / DB 1GB 未満

| 費目 | 案A 最小構成(Render Hobby) | 案B 業務推奨(Render Pro) | 根拠 |
|---|---|---|---|
| WS | $0 | $25 | Render ワークスペース Hobby $0 / Pro $25(公式要約) |
| WEB | $7 | $7 | Starter 512MB/0.5CPU $7(公式要約) |
| WRK | $7 (または Web 内で $0) | $7 | Background Worker に無料枠なし(公式要約) |
| PG | $7.50 | $7.50 | Basic-256mb $6 + 5GB × $0.30(公式要約) |
| BW | 約 $1.05 | $0 | 含まれる転送 Hobby 5GB / Pro 25GB、超過 $0.15/GB(公式要約)。12GB/月と仮定 |
| MAIL | $0 | $20 | Resend Free(3,000通/月・1日100通まで)/ Pro $20(50,000通)(公式要約) |
| BK | 約 $0.04 | 約 $0.04 | R2 $0.015/GB・10GB無料(公式要約) |
| MON | $0 | $0 | 内蔵ログ + 無料の外形監視 |
| **合計** | **約 $23/月**(ワーカーを Web 内にすれば 約 $16) | **約 $67/月** | |

- 案A の注意: Resend Free は1日100通が上限。リマインダーが集中する日に上限に達するおそれ → 予約が1日30件を超えるなら有料プラン推奨。Hobby は PITR 3日・ログ7日(公式要約)。
- 案B の理由: PITR 7日・ログ14日・転送25GB・メンバー無制限。

### B. 中規模: 3店舗 / 20スタッフ / 20,000顧客 / 約6,000予約/月 / 約25,000通/月 / DB 2〜5GB

| 費目 | Render Pro 構成 | 根拠 |
|---|---|---|
| WS | $25 | 公式要約 |
| WEB | $25 | Standard 2GB/1CPU(公式要約) |
| WRK | $7 | Starter |
| PG | 約 $22 | Basic-1gb $19(**第三者サイトのみ・要確認**)+ 10GB × $0.30 |
| BW | 約 $6 | 転送 65GB(アプリ20GB + 毎日のオフサイトバックアップ45GB)と仮定。バックアップ送信を週1にすれば約 $0.2 |
| MAIL | $20 | Resend Pro 50,000通以内 |
| BK | 約 $0.80 | R2(1.5GB × 42世代) |
| MON | $0〜$29 | 有料監視を使う場合 +$29(年払い、公式要約) |
| **合計** | **約 $106〜$135/月** | |

感度: DB を 1CPU/2GB($40, 掲載ページ未特定)にすると 約 $127。HA(スタンバイ)を付けると DB 費用がほぼ2倍。

### C. 代替構成(参考・見積り)
| 構成 | 目安 | 注意 |
|---|---|---|
| DB を Neon Launch | 小規模DB常時稼働で 約 $20〜22/月 | $0.106/CU時間・$0.35/GB-月、最低料金なし(公式要約)。btree_gist 対応(公式) |
| DB を Supabase Pro | $25〜30/月 | PITR は 7日ごとに +$100/月(公式要約)。btree_gist 対応(公式) |
| Railway Pro 一式 | $20/月〜(最低額) | **Hobby は非商用のみ**(公式規約要約)→ 有償SaaSは Pro 必須 |
| Fly.io + Managed Postgres Basic | 約 $47/月 | 無料枠なし |
| 自前 VPS + docker-compose | VPS 料金のみ | バックアップ・更新・監視を自分で行う必要あり(購入者向けには非推奨) |

円換算の例(1 USD = 150円と仮定、実勢で差し替え): 小規模 案B 約 1万円/月、中規模 約 1.6〜2万円/月。消費税(国外事業者のリバースチャージ含む)・カード為替手数料は含まない。

## 4. 無料枠を本番に使わない理由
- Render Free Web は15分無通信でスリープ、Free Postgres は30日で失効(公式要約)。Neon Free は scale-to-zero を無効化できない、Supabase Free は7日無活動で一時停止(公式要約)。予約受付・リマインダーが止まるため本番不可。

## 5. 販売者が確認すること(未確認事項)
1. Render Postgres の Basic-1gb 以上の価格、`btree_gist` 対応、ログストリームの対象プラン、カスタムドメイン数、Hobby の商用可否。
2. Amazon SES の 2026年料金プラン(Essentials 月額)と段階単価。Postmark 上位ティアの超過単価。SendGrid 現行価格。
3. 各社規約での SaaS 提供の扱い(Render は「Render 自体の再販禁止」条項のみ確認、法務確認推奨)。
4. 東京リージョンの有無とレイテンシ(調査範囲外)。
5. 上記すべての金額を公式ページで再確認し、販売ページに記載する場合は「目安」「時期」「税別」を明記。

## 6. 運用コストを下げる設定
- 小規模は `RUN_WORKER=true` で Web 1台に集約。
- オフサイトバックアップは週1 + マネージドDBの PITR で日常復旧(転送量削減)。
- リマインダーは1回(前日)に限定(拠点設定)。
